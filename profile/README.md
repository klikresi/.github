## Tentang Klik Resi

Klik Resi adalah web service (API) agregator pengiriman yang memudahkan pelaku
eCommerce dan developer untuk mengintegrasikan 10+ kurir dalam satu panggilan
API — tanpa biaya langganan, bayar sesuai pemakaian.

## Produk

- **Tracking API** — Lacak paket real-time dari 10+ kurir dalam satu panggilan API.
- **Rates API** — Bandingkan tarif ongkir dari berbagai ekspedisi dalam sekali panggil.
- **Location API** — Cari kodepos dan data wilayah seluruh Indonesia.
- **BYO API** — Gunakan API key kurir milik Anda sendiri, gratis.

Detail harga: [klikresi.com](https://klikresi.com)
